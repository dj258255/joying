# 앞단이 방을 어디로 보내는지 재는 자리

노드가 늘거나 줄 때 방이 얼마나 다른 노드로 옮겨 가는지 잰다.

```
load/routing/measure.sh
ROOMS=5000 load/routing/measure.sh   # 방 수를 바꾸려면
```

## 백엔드를 띄우지 않는 이유

옮겨 가는지는 **앞단의 해시가 정한다.** 뒤에 무엇이 붙어 있든 달라지지 않는다. 백엔드를
띄우면 재는 데 시간이 붙고 저장소와 Redis 가 값에 끼어들 자리만 생긴다.

자기 이름만 돌려주는 껍데기 셋을 두고, 방 번호를 실어 앞단에 보낸 뒤 어느 이름이
돌아오는지 읽는다.

## 무엇을 세나

- **옮겨 간 방 수** — 노드를 2→3 으로 늘리고, 다시 3→2 로 줄이면서 각각 센다
- **어디로 옮겼나** — 새로 들어온 노드로 간 것과, 멀쩡히 있던 노드끼리 자리를 바꾼 것을
  가른다. 뒤엣것은 **끊을 이유가 없는 연결을 끊는 것**이다
- **노드별 방 수** — 전부 한 노드로 몰리면 옮겨 간 방이 적은 것이 좋은 뜻이 아니다

`consistent` 를 붙인 것과 뺀 것을 나란히 돌린다. 비교 대상이 없으면 나온 값이 좋은
것인지 알 수 없다.

## 결정적이다

해시는 같은 입력에 같은 답을 준다. 여러 번 돌려도 값이 같으므로 반복 실행이 필요 없다.
