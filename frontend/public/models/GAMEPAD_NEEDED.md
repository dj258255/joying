# Gamepad 3D Model 필요

## 파일 위치
`public/models/gamepad.glb`

## 준비 방법
1. Blender에서 게임패드 모델 제작
2. GLB 형식으로 export
3. 이 폴더에 `gamepad.glb`로 저장

## 또는
무료 3D 모델 사이트에서 다운로드:
- https://sketchfab.com/ (Free 필터)
- https://poly.pizza/
- https://free3d.com/

## Export 설정 (Blender)
- Format: glTF Binary (.glb)
- Include: Selected Objects
- Transform: +Y Up
- Geometry: Apply Modifiers ✓
- Compression: Draco ✓
