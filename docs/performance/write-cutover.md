# 정본을 새 DB 로 교대했다 (쓰기 컷오버)

[무중단 이관](live-storage-split.md)과 [읽기 전환](read-switch-shadow.md)의 마지막
조각이다. 정본이 옛 DB 인 동안 분리는 끝난 것이 아니다. 송신 저장과 멱등 중재를
새 DB 로 옮기고, 옛 DB 는 되돌림을 위한 역방향 미러로 남긴다. 가설과 판정 기준은
[#123](https://github.com/dj258255/joying/issues/123)에 먼저 적었다.

결론부터.

- **송신이 흐르는 가운데 정본이 바뀌었고 깨진 것이 없다.** 배리어 473ms(기준
  2초) 안에서 꼬리 백필(0행) · 끝 검증 · 두 노드 모드 전환이 끝났고, 그 실행의
  송신 1,200건은 유실 0 · 뒤집힘 0
- **교대 후 전달은 교대 전과 동급이다.** p95 중앙값 79ms 대 75ms(1.05배, 기준
  1.5배). 쓰기 비용 구조가 대칭(정본 1회 + 미러 1회)이라는 예상대로다
- **멱등의 심판이 새 DB 로 옮겨 왔다.** 같은 식별자 10개 × 3회 전송(30건)에
  양쪽 DB 모두 10행만 늘고 멱등 히트가 정확히 20
- **되돌림도 모드 복귀로 끝났다.** 배리어 352ms · 유실 0, 되돌림 후 행 수
  154,830 · 꼬리 · 해시 표본이 양쪽 일치. new-primary 구간의 10,810행을
  역방향 미러가 옛 DB 에 채웠다는 증거다

## 구조

- 모드가 런타임 상태가 된다(`joying.chat.migration.mode`: off · dual-write ·
  new-primary). 교대는 쓰기 배리어 아래에서만 받는다. 모드는 노드별 메모리
  상태라 두 노드가 잠깐 다른 정본으로 살 수 있는데, 배리어가 그 창의 새 저장을
  막는다
- new-primary 의 저장은 새 DB 에 INSERT ... ON CONFLICT(조건부 유니크
  uk_chat_message_client_id)로 들어간다. 같은 전송을 한 번만 저장하는 심판이
  정본과 함께 옮겨 온다. 0행이면 먼저 저장된 행을 읽어 멱등 히트로 처리한다.
  정본 삽입 실패는 미러와 달리 송신 실패라 예외를 그대로 올린다
- 옛 DB 는 역방향 미러를 받는다. 전체 행을 계속 가지므로 되돌림이 모드 복귀로
  끝나고, 옛 DB 를 보는 나머지 읽기(검색 · 단건 · 답장 원본)도 그대로 산다
- 수정 · 삭제 · 읽음의 새 DB 미러는 교대 뒤 실패를 올린다(fail-closed). 지운
  메시지가 정본 읽기에 살아 있는 것을 세기만 하면 노출 창이 조용히 열린다
- 시스템 메시지는 송신 경로 밖이라 저장 자리에서 새 DB 미러를 따로 태운다.
  이중 쓰기 기간에도 백필 전까지 새 DB 에 없던 자리다
- 컷오버 스크립트(scripts/cutover-chat-split.sh)가 배리어 → 꼬리 백필 → 끝
  검증 → SWITCH_MODE 전환 → 해제를 한 번에 한다. 끝이 다르면 전환 없이
  배리어만 내리고 실패로 끝난다. 되돌림도 같은 문이라, 역방향 미러가 빠뜨린
  행이 있으면 끝 비교가 되돌림을 막는다

## 대가

- 교대 뒤에도 쓰기는 두 번이다(새 DB 정본 + 옛 DB 역미러). 옛 DB 를 보는
  읽기가 남아 있는 동안은 끊을 수 없는 비용이다
- 역방향 미러 실패는 송신을 막지 않고 센다(옛 DB 장애가 송신을 막으면 교대의
  의미가 없다). 그 동안 옛 DB 를 보는 검색 · 단건 조회는 빠진 행을 모를 수
  있고, 되돌림은 끝 비교가 막는다. 미러 실패 지표가 0이 아니면 역방향을 메우기
  전까지 되돌리지 않는 것이 운영 규칙이다
- 수정 · 삭제 · 읽음은 교대 뒤 새 DB 실패가 작업 실패가 된다(fail-closed).
  노출 창을 닫는 값으로 가용성 한 겹을 냈다

## 아직 하지 않은 것

- **옛 DB 읽기의 이주.** 검색 · 단건 · 답장 원본이 아직 옛 DB 를 본다. 전부
  옮기면 역방향 미러를 끊고 옛 DB 의 chat_message 를 걷을 수 있다
- **역방향 재동기화 도구.** 미러 실패분을 메우는 백필은 옛→새 방향만 있다.
  반대 방향은 지금은 손으로 해야 한다
- **두 번째 교대 리허설의 반복.** 교대 → 되돌림을 한 번씩 쟀다. 반복 왕복에서
  배리어 시간이 어떻게 분포하는지는 더 재지 않았다
